# Synthetic example-irregular model of the inverted-pyramid model

This example shows an irregular inverted-pyramid density model.

It is paired with:
- `shifted_inverted_pyramid_test.vti`
- 2D slice views
- 3D slice views
- voxel and isosurface visualizations

The folder is intended to keep the prediction, ground-truth, and field-response figures together for direct inspection on GitHub.
